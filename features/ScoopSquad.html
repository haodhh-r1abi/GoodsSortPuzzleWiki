Mô tả

  • Scoop Squad (Biệt đội bán Kem) là sự kiện hợp tác với bạn bè — trong code là Star Collaboration.
  • Thắng màn để nhận Sữa (Milk); dùng sữa quay vòng quay để nhận Muỗng Kem (Scoop).
  • Muỗng kem tích vào tiến độ xây các món kem của cả biệt đội (tối đa 4 thành viên).
  • Vượt các mốc điểm nhận thưởng tiến độ; hoàn thành toàn bộ nhận Giải Lớn là khung avatar kem độc quyền.
  • Có thể mời bạn bè hoặc cả team cùng tham gia.

Còn thiếu / chưa xác minh

📌 Điểm số, xác suất vòng quay và thưởng do server đẩy (EncryptedInt/EncryptedFloat); client không có số baked.
📌 get_NumMilkToSpin là ObscuredInt tính runtime, không lộ giá trị tĩnh.
📌 Sự kiện server-authoritative, mở ở màn 41 nên không chụp ảnh live; minh họa dùng sprite APK (~168 PNG).

Mở khóa & điểm vào

Mở ở màn 41: StarCollaborationDataController.IsUnLock() trả true khi Level > 0x28 (40); hằng số level_unlock = 41. Popup giới thiệu được phép hiện sớm từ màn 30 (CanShowPopup: Level > 0x1d (29); hằng số level_can_show_popup = 30).

Điểm vào:

  • Biểu tượng Scoop Squad ở Home (UI_Home_Listing_ScoopSquad)
  • Popup chính (UIPopup_ScoopSquad) với vòng quay và tiến độ
  • Popup mời bạn bè (UIPopup_ScoopSquad_InviteFriends)
  • Tin nhắn mời trong team (UIClan_TeamMessage_ScoopSquad_Item)

Cách hoạt động

  1. GetStarCollabInfo hỏi server trạng thái sự kiện (thành viên, điểm, thời gian, Giải Lớn).
  2. Thắng màn -> CompleteLevel tích Sữa (get_MilkReceiveFromLevel).
  3. Đủ sữa -> Spin: GetIndexByRatioInArray chọn ô theo StarCollabLuckyWheelSheet.chance, server trả kết quả qua SCSpinStarCollab.
  4. Điểm quy ra mốc (StarCollabProgressSheet); ClaimRewardProgress nhận thưởng mốc.
  5. Hoàn thành -> ClaimGrandReward: FrameCollectionController.AddNewFrame cấp khung kem (frame_id = -2).
  6. InviteFriend / InviteTeamStarCollab mời tối đa 4 thành viên; ResponRequest để chấp nhận/từ chối.
Luồng chi tiết theo code

Init() nạp log (scoop_log) và kiểm tra CanShowPopup. GetStarCollabInfo() hỏi server thông tin sự kiện; GetStarCollabInfoFromServer(SCGetStarCollabInfo) nạp trạng thái: _state, _timeEnd, _milk, _userInfoCollabs (các thành viên), _grandReward, targetPoints, ratios. Thắng màn -> CompleteLevel() tích Sữa (get_MilkReceiveFromLevel), ConfirmReceiveMilkFromLevel() xác nhận. Khi đủ sữa (get_NumMilkToSpin, ObscuredInt) và CanSpin() đúng -> Spin(collabIndex): CollectionUtils.GetIndexByRatioInArray chọn ô trúng theo StarCollabLuckyWheelSheet (chance EncryptedFloat, type, score), gửi CSSpinStarCollab, server trả SCSpinStarCollab -> nhận Scoop/điểm. Điểm quy ra mốc qua StarCollabProgressSheet (score + rewardType[]/rewardValue[]); GetRewardState / ClaimRewardProgress(collabIndex, rewardIndex) nhận thưởng mốc. Mời thành viên: GetSuggestFriend, InviteFriend(code), InviteTeamStarCollab (tối đa max_slot = 4, num_partner = 4), phản hồi qua ResponRequest. Hoàn thành toàn bộ -> CanClaimGrandReward() -> ClaimGrandReward() -> ClaimGrandRewardFromServer cấp khung kem (FrameCollectionController.AddNewFrame, frame_id = -2). Hết hạn -> ConfirmEnd() ghi log funnel và reset spin type.

Chưa đọc được / ghi chú

  • Toàn bộ điểm số, xác suất vòng quay và thưởng (StarCollabLuckyWheelSheet, StarCollabProgressSheet, StarCollabGrantRewardSheet) do server đẩy qua ClientClassConverter (EncryptedInt/EncryptedFloat); client không có số baked.

  • Sự kiện server-authoritative (CS/SC) và mở ở màn 41 nên không spoof/chụp live được; minh họa dùng sprite APK (ScoopSquad ~168 PNG).
